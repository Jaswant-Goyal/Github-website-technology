# Github-website-technology

1) Create new folder inside a project in GitHub website<br>
first navigate to your repository where you want to add the folder<br>
click add file button then select create new file<br>
In "Name your file" field -> type the folder name, followed by a forward slash / <br>
for example: res/layout/<br>
then immediately after the slash, type a name for a file inside that folder (just type dummy file name).<br>
commit changes. <br>
